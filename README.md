# Source code for [Boyd's Blog][1]

Generated using [quartz][2]. See the source for the essays in `content/`.

## AISCT lonely drafts club writing procedure

- quick writing exercises before we start
- comfort level with critique
- review structure:
  - commentary done mostly verbal, rather than writing everything out
  - author can jot down notes from verbal discussion
- Authors to give the reviewers an idea about what they want to be reviewed
- the feedback process is tricky, needs more optimisation

## Running locally

```
npx quartz build --serve
```

## Pushing changes

```
npx quartz sync
```
