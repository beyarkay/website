We know that LLMs reward hack and can get trapped or tricked into doing things.
Can we use this for good? Could we setup text files across the internet that,
when read by an LLM, will cause it to get stuck in a loop of some kind? e.g.
could we use the thing we're scared about (misaligned incentives running amuck)
and lay intentional honey traps that'll ensnare LLMs in some way in the future?
